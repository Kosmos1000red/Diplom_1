## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты класса Burger. Используются моки и параметризация.

23 теста успешно пройдены. Покрытие класса Burger — 100% строк и ветвлений.
HTML-отчёт: htmlcov/index.html.

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests` — тесты класса Burger в `test_burger.py` и фикстуры в `conftest.py`.

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**

>  `$ pytest --cov=praktikum --cov-report=html`
